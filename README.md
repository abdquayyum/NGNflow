# Fngn Frontend (React Native)

This project is built with React Native (Expo) and styled with NativeWind (Tailwind CSS for React Native).

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Expo server:
   ```bash
   npx expo start
   ```

3. Press `i` to open in iOS Simulator, or `a` to open in Android Emulator.
